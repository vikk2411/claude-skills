## Pediatric Dosing Quick Reference (Weight-Based)

> Always confirm weight before dosing for children <12 years

| Drug | Dose | Max |
|---|---|---|
| Paracetamol | 15 mg/kg/dose q4–6h | 4 doses/day, 60mg/kg/day |
| Ibuprofen | 10 mg/kg/dose q6–8h | Avoid <6 months |
| Amoxicillin | 25–50 mg/kg/day divided q8h | 500mg/dose |
| Amoxicillin-Clavulanate | 25–45 mg/kg/day (Amox component) divided q8h | |
| Azithromycin | 10 mg/kg on Day 1, then 5 mg/kg Days 2–5 | 500mg/day |
| Cetirizine | 0.25 mg/kg/dose once daily | 10mg/day |
| Levocetirizine | 0.125 mg/kg once daily | 5mg/day |
| Domperidone | 0.25 mg/kg/dose TDS before food | |
| Ondansetron | 0.15 mg/kg/dose q8h | 4mg/dose |
| Metronidazole | 7.5 mg/kg/dose q8h | 400mg/dose |
| Ambroxol | 1.2–1.6 mg/kg/day divided | |
| Montelukast | <6 yrs: 4mg; 6–14 yrs: 5mg; >14 yrs: 10mg | Once daily at night |
| Albendazole | <2 yrs: 200mg single dose; >2 yrs: 400mg single dose | |
| Zinc | 10mg/day <6 months; 20mg/day >6 months (for diarrhoea) | 14 days |
| ORS | As tolerated — 50–100ml/kg over 2–4h for mild dehydration | |

## Contraindications Quick Reference

| Drug Class | Avoid in |
|---|---|
| NSAIDs (Ibuprofen, Diclofenac, Nimesulide) | Pregnancy (esp. 3rd trimester), peptic ulcer, renal failure, <3 months age |
| Fluoroquinolones | Children <18 years (cartilage risk), pregnancy |
| Tetracyclines/Doxycycline | Children <8 years, pregnancy |
| Metronidazole | 1st trimester pregnancy |
| Nimesulide | Children <12 years, liver disease |
| Loperamide | Children <2 years, bloody diarrhoea |
| Strong steroids (Clobetasol) | Face, groin long-term; pregnancy |
| Tamsulosin | Females |
